# Rohan Ankush Jadhav — Portfolio

Welcome to my personal portfolio! I am an AI & Data Science Engineer building intelligent systems that solve real-world problems at scale. 

This portfolio showcases my work across Quantum Computing, Natural Language Processing, and Artificial Intelligence, packaged in a highly interactive 3D web experience.

## ✨ Features

- **Interactive 3D Environments:** Custom-built React Three Fiber canvas graphics and a fully interactive data-cluster constellation graph representing my technical stack.
- **Scroll Reveal Animations:** Smooth, cinematic fade-in scroll effects driven by custom IntersectionObserver hooks.
- **Dynamic Sticky Layouts:** Complex CSS layouts for showcasing selected case studies with dynamic split-scroll architecture.
- **Next.js 14 (App Router):** Built completely on the newest Next.js App Router for optimal performance, SSR, and SEO.
- **TypeScript & Tailwind CSS:** Fully typed, extremely scalable, and elegantly styled.

## 🛠️ Technology Stack

- **Framework:** [Next.js](https://nextjs.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **3D Graphics:** [Three.js](https://threejs.org/) & [React Three Fiber](https://docs.pmnd.rs/react-three-fiber)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Deployment:** [Vercel](https://vercel.com)

## 🚀 Getting Started

To run this project locally:

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) in your browser.
